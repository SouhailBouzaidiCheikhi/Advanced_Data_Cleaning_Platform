# 🧼 Advanced Data Cleaning Platform

An **advanced, interactive, and crash-proof data cleaning web application** built with **Streamlit**.  
This app allows users to clean, preprocess, and export datasets **without writing code**.

> 🎯 Perfect for Data Science, Machine Learning, and Analytics projects.

---

## 🚀 Features

- 📂 Upload CSV datasets
- 🔍 Automatic data type detection
- 🧩 Missing value imputation (numeric & categorical)
- 🗑️ Duplicate removal
- 📉 Outlier removal (IQR method)
- 📐 Data scaling (Standard / MinMax)
- 🔠 Categorical encoding
- ⬇️ Export cleaned dataset
- ⚠️ Crash-proof & user-safe

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Pandas**
- **NumPy**
- **Scikit-learn**

## ▶️ How to Run the Application

### 1️⃣ Clone the repository
```bash
git clone https://github.com/YourUsername/Advanced_Data_Cleaning_Platform.git
cd Advanced_Data_Cleaning_Platform
```
### 2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```
### 3️⃣ Run the Streamlit app

```bash
streamlit run app.py
```
